# WorkTimeBot — Telegram-бот для учёта рабочего времени

**WorkTimeBot** — C++20 Telegram-бот для учёта смен сотрудников с расчётом заработка, надбавок и еженедельных премий.

## Возможности

- **Регистрация сотрудников** — имя, часовая ставка (200/225/250/280 руб/ч), надбавка 25 руб/ч
- **Учёт смен** — начало и окончание смены с выбором времени (±30 мин от текущего)
- **Мгновенный расчёт** — после завершения смены бот показывает отработанные часы, сумму по ставке и надбавку
- **История и отчёты** — просмотр отработанных смен и заработка за текущую неделю, прошлую неделю или текущий месяц
- **Автоматическая еженедельная рассылка** — каждый понедельник в 06:00 бот отправляет отчёт за прошлую неделю всем сотрудникам
- **Премиальная система** — при 5+ сменах за неделю с обязательной отработкой пятницы и субботы начисляется премия: 5 смен → 3000₽, 6 смен → 3500₽, 7+ смен → 4000₽
- **Настройки профиля** — изменение имени, ставки и включение/отключение надбавки через inline-меню

## Быстрый старт

### Локальная сборка

Требования: CMake ≥ 3.20, vcpkg, компилятор с поддержкой C++20.

```bash
# Клонировать репозиторий
git clone https://github.com/yourname/WorkTimeBot.git
cd WorkTimeBot

# Установить зависимости через vcpkg
vcpkg install --triplet x64-windows

# Собрать проект
cmake -B build -DCMAKE_TOOLCHAIN_FILE=/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build

# Запустить (токен через переменную окружения)
set BOT_TOKEN=your_telegram_bot_token
build\WorkTimeBot.exe
```

### Docker (рекомендуемый способ)

```bash
docker build -t worktimebot .
docker run -e BOT_TOKEN=your_telegram_bot_token -v worktime_data:/app/data worktimebot
```

Для Coolify достаточно указать переменную окружения `BOT_TOKEN` и смонтировать persistent storage в `/app/data`.

## База данных

Файл БД создаётся автоматически в папке `./data/worktime.db` при первом запуске. Таблицы:

- **users** — id, имя, ставка, наличие надбавки
- **shifts** — id, user_id, время начала и окончания смены
- **settings** — ключ-значение для системных настроек (дата последней рассылки)
